# ChronoNote · 智能时间流记事与待办

> 一句话记下，自动落到时间轴上。本地优先、双击即开，多端通过 GitHub Gist 无损同步。

**在线使用：** https://l2036363518-lab.github.io/chrononote/

---

## 简介

ChronoNote 是一个**单文件网页应用** —— 全部代码在一个 `index.html` 里，没有构建步骤、没有后端、没有账号体系。

在一个输入框里写下：

```
明天下午3点 交周报 // 附上合同 https://a.com
```

它会自动拆成三样东西：标题「交周报」、时间「明天 15:00」、两条子备注（文字「附上合同」+ 链接 `a.com`）。

数据默认只存在**你自己浏览器的 IndexedDB** 里；需要跨设备时，接上自己的 GitHub Gist 做双向增量合并，不经过任何第三方服务器。

## 功能

### 1. 一个输入框完成录入

- 回车即发送，`Shift + 回车` 换行
- ` // `（空格 双斜杠 空格）之后的文字自动变成子备注；其中的 URL 自动识别为链接备注
- 输入框内 `Ctrl + V` 直接粘贴截图，自动压缩后作为图片备注
- 输入过程中实时显示时间属性胶囊，发送前可点击修改

### 2. 双引擎时间解析

| 引擎 | 触发方式 | 特点 |
|---|---|---|
| 本地正则 | 默认，实时 | 零延迟、零网络、完全离线可用 |
| DeepSeek AI | 点 ✨ 按钮 | 一句话里的多件事自动拆成多条任务，需要自备 API Key |

### 3. 三个视图，各归其位

- **时间轴**：过期 → 今天 → 明天 → 未来具体日期，按天分组；同一天内精确时间按 `00:00→23:59` 排序，全天事项排在其后
- **近期规划**：三天内 → 本周 → 下周 → 两周内 → 本月 → 下月 → 今年内 → 远期，共 8 档
- **琐事箱**：没有时间限制的杂事，按创建时间倒序

### 4. 今日计划面板

时间轴顶部的固定面板：今日完成进度条、待办与逾期计数，以及一个「加到今天」的快捷输入框。带时间的按时间建，没时间的落到今天全天。

### 5. 子备注

每个任务可挂载三类备注：文字（保留换行、可反复编辑）、链接（带域名胶囊、新标签页打开）、图片（自动压缩、网格缩略图、点开全屏灯箱）。

### 6. 跨端同步

GitHub Gist 双向增量合并：

1. 只在一边存在的任务，直接并入
2. 两边都有，按 `updatedAt` 保留更新的那份
3. 删除是写 `deleted: true` 并刷新时间戳，所以删除也能同步，且不会在另一台设备上"复活"

合并完成后同时写回本地与云端；页面打开时会自动同步一次，本地改动后 8 秒也会静默推送一次（同步自身的写回已屏蔽，不会自触发循环）。

## 时间语法速查

| 你写的 | 解析成 |
|---|---|
| `明天下午3点半 交周报` | 明天 `15:30` |
| `后天中午12点 出发` | 后天 `12:00` |
| `本周三 评审` | 本周三，全天 |
| `下周一 例会` | 下周一，全天 |
| `11月8日 体检` / `2026-12-01 续费` | 对应日期，全天 |
| `9:30 站会` | `09:30`（今天已过则顺延到明天） |
| `今晚8点 跑步` / `明早7点 晨跑` | 今天 `20:00` / 明天 `07:00` |
| `3天后 交初稿` / `2周后 复查` | 今天 +3 天 / +14 天，全天 |
| `2小时后 关火` / `半小时后 回电话` / `20分钟后 出门` | 从当前时刻起算的精确时间 |
| `三天内 交材料` | 三天内 |
| `两周内 体检` / `半个月内 修好打印机` | 两周内 |
| `下个月 交房租` | 下月 |
| `今年内 考完驾照` / `年底前` | 今年内 |
| `有空 整理照片` / `近期` / `改天` | 远期 |
| `买洗衣液` | 琐事箱（无日期） |

> 数字口语也认：`下午两点半`、`晚上八点`、`十一`、`二十一`。

## 数据与隐私

- **任务与图片**：存在浏览器的 IndexedDB（localforage），不经过任何服务器
- **配置项**：`deepseekApiKey`、`githubToken`、`gistId`、`lastIsoWeek` 四项存在 localStorage
- **同步**：只写到你自己账号下的私密 Gist，本应用没有任何中转服务
- **注意**：GitHub 的 secret gist 只是"不被搜索到"，不是加密；拿到链接的人可以读取，别存放密码等敏感信息
- 已删除的事项只保留墓碑（去掉图片），超过 30 天自动物理清除；若某台设备离线超过 30 天，其本地旧副本同步回来时可能让该事项"复活"

想清空本地数据：设置 → 数据 → 清空全部。

## 快速开始

**直接用：** 打开 https://l2036363518-lab.github.io/chrononote/

**离线用：** 下载 `index.html`，双击即可（首次加载需要联网取 CDN 依赖）

**开同步：**

1. 到 [github.com/settings/tokens](https://github.com/settings/tokens) 创建 **classic** token，只勾 `gist` 一项（fine-grained token 不支持 Gist）
2. 应用内 设置 → 跨端同步 → 填 Token，Gist ID 留空 → 点「立即同步」，会自动创建 Gist 并回填 ID
3. 其他设备填**同一个 Token + 同一个 Gist ID**

## 更新部署

本仓库即站点源：

1. 用新的 `index.html` 覆盖仓库里的同名文件（`Add file → Upload files`）
2. Settings → Pages 已配置为 `main` / `root`，提交后约 1 分钟自动重建
3. 各端刷新页面即生效

## 技术栈

Vue 3（全局构建 CDN）· Tailwind CSS（CDN）· Lucide Icons（CDN）· LocalForage（IndexedDB）· 原生 Canvas 图片压缩 · 原生 Fetch

无构建、无依赖安装、无 Node 运行时。

---

## 已知限制

- 首次打开需联网加载 CDN 依赖；断网后依赖浏览器缓存
- 没有 manifest / Service Worker，安卓加桌面是快捷方式（iOS 加主屏可全屏运行）
- 同步在页面打开时自动执行一次，本地改动后 8 秒自动推送；想看即时状态可手动点「立即同步」
- AI 拆解依赖 DeepSeek API，Key 与网络均需自备
